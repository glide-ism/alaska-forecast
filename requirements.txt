# Dependencies for alaska-forecast.
#
# This repo is an experiment/orchestration workspace, not an installable
# package. To set up an environment:
#
#     pip install -r requirements.txt
#
# NOTE: the geospatial stack (rasterio/rioxarray/geopandas -> GDAL/PROJ) and
# the GPU stack (cupy/torch -> CUDA) can be painful to install via pip wheels.
# The custom libraries below pin `cupy-cuda13x`, which requires a CUDA 13.x
# toolkit; on a different CUDA version, install the matching cupy wheel first.

# --- custom libraries (github.com/glide-ism), tracking main ---

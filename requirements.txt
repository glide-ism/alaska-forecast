# Dependencies for alaska-forecast.

# package. To set up an environment:
#

# NOTE: the geospatial stack (rasterio/rioxarray/geopandas -> GDAL/PROJ) and
# the GPU stack (cupy/torch -> CUDA) can be painful to install via pip wheels.

# --- GPU: CuPy ---
# CuPy ships a separate binary wheel per CUDA major version (no universal wheel),
# so the custom libraries below leave it optional. Pick the ONE matching your
# CUDA toolkit (cuda12 is the default; uncomment another and comment this out):
# cupy-cuda11x>=12.0.0
